Для диагностики и интеграции оборудования, работающего по CAN шине, удобно использовать базу всех сообщений - DBC файл.

Актуальную версию файла DBC можно скачать по ссылке ниже:

https://raw.githubusercontent.com/Konstantin-Dudersky/plc-modules/main/firmware/ek_modules.dbc

## Генерация кода

На основе файла DBC можно генерировать код для кодирования и декодирования сообщений.

## dbcUtility

Есть большое количество программ для просмотра и редактирования файлов CAN DBC. Можно рекомендовать бесплатную кроссплатформенную утилиту [dbcUtility](https://github.com/busaudit/dbcUtility).
