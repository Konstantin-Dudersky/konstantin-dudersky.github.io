Основные характеристики:
- 4 независимых канала.
- Подключение терморезистивных датчиков по ГОСТ 6651-2009:
  - Платина (Pt-100, Pt-1000): α = 0,00385, α = 0,00391;
  - Медь (Cu-100, Cu-1000): α = 0,00428;
  - Никель (Ni-100, Ni-120, Ni-1000): α = 0,00617.
- Возможно подключение по 2, 3 и 4 проводным схемам.
- Погрешность измерения не более 0,5 °C (для Pt-100, Pt-1000).
- Диагностика подключения датчика: короткое замыкание и обрыв.
- Передача данных через гальванически изолированный CAN-интерфейс.

Область применения:
- Технологические процессы, в которых требуется высокоточное измерение температуры с помощью RTD-датчиков.
- Контроль температуры в системах вентиляции, отопления и кондиционирования (HVAC).
- Контроль температуры оборудования: подшипников, обмоток двигателей, холодильных установок.
- Лабораторное и испытательное оборудование, в котором RTD датчики могут обеспечить точность и стабильность измерений

Кроме указанных датчиков, возможно подключение и других типов терморезистивных RTD датчиков с отличным температурным коэффициентом. В сообщении CAN вместе со значением температуры передаётся и значение измеренного сопротивления; то есть можно реализовать собственное преобразование сопротивления в температуру.

Для измерения сопротивления используется АЦП **MAX31865**.

При 2-проводном подключении необходимо установить перемычки между клеммами **RTN** и **R-**, **SRC** и **R+**.

При 3-проводном подключении необходимо установить перемычку между клеммами **RTN** и **R-**.

Для корректного измерения тип схемы (2, 3 или 4 проводная) необходимо задать в настройках модуля.

[EKMC-ESP32C3](/modules/description/ekmc-esp32c3) - плата с микроконтроллером ESP32-C3 для управления работой модуля. Выполняет следующие функции:
- конфигурирует АЦП MAX31865 по протоколу SPI
- последовательно опрашивает измеренные значения в АЦП MAX31865
- управляет светодиодной индикацией через расширитель портов MCP23017 по протоколу I²C
- передаёт данные измерения через шину CAN

Для определения сопротивления тероморезистивных датчиков используется АЦП MAX31865. АЦП измеряет отношение сопротивления терморезистора к опорному резистору. Далее по таблицам ГОСТ 6651-2009 по значению сопротивления определяется температура.

Распиновка микроконтроллера ESP32-C3:
- SPI:
  - MOSI - GPIO 2
  - MISO - GPIO 3
  - SCK - GPIO 4
  - CS0 (CH0) - GPIO 5
  - CS1 (CH1) - GPIO 6
  - CS2 (CH2) - GPIO 7
  - CS3 (CH3) - GPIO 8
- I²C:
  - SDA - GPIO 0
  - SCL - GPIO 1
- CAN:
  - RX - GPIO 21
  - TX - GPIO 20
