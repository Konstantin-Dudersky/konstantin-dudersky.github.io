## Описание

Для формирования аналоговых выходов используется микросхема **MCP4728** — четырёхканальный ЦАП с интерфейсом I²C. Она получает цифровые значения уставок и формирует по одному аналоговому сигналу на каждый канал.

Для токового выхода 4-20 мА используется **XTR111**. Этот чип преобразует управляющее напряжение в токовый сигнал, удобный для передачи по промышленным линиям связи и подключения стандартных токовых входов.

В зависимости от исполнения канала выход может использоваться для формирования сигнала 0-10 В или 4-20 мА. Такой подход позволяет применять модуль для управления различными типами исполнительных устройств.
