Основные характеристики:

- 4 независимых канала аналогового выхода
- стандартные промышленные сигналы 0–10 В и 0–20 мА (4–20 мА)
- разрешение ЦАП 12 бит
- управление через гальванически изолированный CAN-интерфейс

Область применения:

- управление частотными приводами (задание частоты или момента) и сервоприводами с аналоговым входом
- управление открытием регулирующих клапанов и заслонок
- задание производительности дозаторов, насосов
- задание уставки для внешних регуляторов
- управление яркостью светильников с диммированием

В модуле используется цифро-аналоговый преобразователь с разрешением 12 бит. Это даёт 4096 дискретных уровней выходного сигнала. Величина одного шага:

- для сигнала 0–10 В — 2,4 мВ
- для сигнала 0–20 мА — 4,9 мкА

Сигнал 4–20 мА получается из 0–20 мА путём программного ограничения диапазона. Следовательно, разрешение сигнала 4–20 мА немного меньше и составляет примерно 11,7 бит.

Тип выходного сигнала (напряжение 0–10 В или ток 0–20мА) выбирается с помощью перемычки на плате.

## Описание

Для формирования аналоговых выходов используется микросхема **MCP4728** — четырёхканальный ЦАП с интерфейсом I²C. Она получает цифровые значения уставок и формирует по одному аналоговому сигналу на каждый канал.

Для токового выхода 4–20 мА используется **XTR111**. Этот чип преобразует управляющее напряжение в токовый сигнал, удобный для передачи по промышленным линиям связи и подключения стандартных токовых входов.

В зависимости от исполнения канала выход может использоваться для формирования сигнала 0–10 В или 4–20 мА. Такой подход позволяет применять модуль для управления различными типами исполнительных устройств.
