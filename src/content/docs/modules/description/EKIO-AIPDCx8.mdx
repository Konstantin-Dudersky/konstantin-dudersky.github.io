## Описание

Для измерения тока и напряжения используется чип **INA226**. Напряжение измеряется непосредственно, а ток - за счёт измерения падения напряжения на шунте. Сопротивление шунта определяет максимальный ток, который может быть измерен **INA226**. В таблице приводится некоторые значения сопротивлений шунта.

| $R_{shunt}$, [Ом] | $I_{max}$, [A] | $P_{shunt}$, [Вт] | $I_{1LSB}$, [мкA] |
| --- | --- | --- | --- |
| 0,015 | 5,4 | 0,44 | 166,7 |
| 0,030 | 2,7 | 0,22 | 83,3 |
| 0,050 | 1,6 | 0,13 | 50 |
| 0,100 | 0,8 | 0,07 | 25 |
| 0,200 | 0,4 | 0,03 | 12,5 |

- $R_{shunt}$ - сопротивление шунта, Ом
- $I_{max}$ - максимальный ток, [A]. Определяется формулой $I_{max} = \frac{V_{max}}{R_{shunt}} $, где $V_{max} = 0,08192 В$ - из документации на **INA226**.
- $P_{shunt}$ - рассеиваемая мощность на шунте, [Вт]. Определяется формулой $P_{shunt} = I_{max}^2 \cdot R_{shunt}$. В плате модуля предусмотрено посадочное место для шунтов типоразмера 2512. Для такого типоразмера рассеиваемая мощность не должна превышать 2 Вт.
- $I_{1LSB}$ - разрешение измерения тока. Определяется формулой $I_{1LSB} = \frac{V_{1LSB}}{R_{shunt}}$. $V_{1LSB} = 2,5 мкВ$ - из документации на **INA226**.

Максимальный ток ограничен размером дорожек на печатной плате. В данном модуле ток не должен превышать 5 А.

Чем меньше значение сопротивления шунта, тем ниже разрешение измерения тока $I_{1LSB}$.
