Основные характеристики:
- 8 каналов интерфейса I²C, подключенных через мультиплексор
- Напряжение питания: 3,3 В или 5 В, выбирается поканально
- Передача данных через гальванически изолированный CAN-интерфейс

Область применения:
- Создание шлюза передачи данных между шинами I²C и CAN
- Интеграция интеллектуальных датчиков I²C в промышленную автоматику
- Построение распределённой системы сбора данных с датчиков I²C
- Передача данных с датчиков I²C на большие расстояния

Все каналы подключены через I²C-мультиплексор **TCA9548A**. К разным каналам можно подключать устройства с одинаковым адресом.

На модуле есть посадочные места для установки изолированных блоков питания 24В / 5В и 24 В / 3,3 В. Блок питания на 3,3 В устанавливается обязательно. Блок питания на 5 В устанавливается опционально - при необходимости запитать устройства от 5 В. Напряжение на каждом канале выбирается с помощью перемычек. Мультиплексор **TCA9548A** позволяет использовать разное напряжение на разных каналах.

Для индикации активности передачи подключается модуль [EKLD-10](/modules/description/ekld-10). Светодиоды подключаются через P-канальные MOSFET к линиям SDA и загораются при активной передаче (когда линия SDA подтянута к земле).

## Описание

<Schematic />

Питание подключаемых устройств осуществляется через изолированный блок питания **B2405** или **B2403** мощностью от 1 до 3 Вт.

Шина I²C гальванически изолирована от шины IBus с помощью I²C-изолятора **CA-IS3021**. Рабочее напряжение логики на разных сторонах изолятора может быть разным (как 3,3 В, так и 5 В). Поэтому к данному модулю можно подключать периферийные устройства с работой от 5 В, даже несмотря на то, что модули контроллеров работают с логикой 3,3 В.

Отдельные каналы подключены через I²C-мультиплексор **TCA9548A**. Поэтому к разным каналам можно подключать устройства с одинаковым адресом I²C.

Пины A0, A1, A2 чипа **TCA9548A** подключены к земле. Адрес по шине I²C - `0x70`.

Нумерация каналов чипа **TCA9548A** не совпадает с нумерацией каналов на модуле - в приоритетах разводки платы было использование 2 слоев с минимум переходных отверстий.

## Примеры работы в Linux

При использовании контроллера, работающего на ОС Linux, можно проверить работу модуля из консоли.

В примере принято:
- адрес чипа **TCA9548A** 0x70
- устройство Linux `/dev/i2c-0`

```sh
# Проверить доступность
i2cdetect -y 0

# Открыть каналы TCA9548A с 0 по 7
i2ctransfer -y 0 w1@0x70 0x01
i2ctransfer -y 0 w1@0x70 0x02
i2ctransfer -y 0 w1@0x70 0x04
i2ctransfer -y 0 w1@0x70 0x08
i2ctransfer -y 0 w1@0x70 0x10
i2ctransfer -y 0 w1@0x70 0x20
i2ctransfer -y 0 w1@0x70 0x40
i2ctransfer -y 0 w1@0x70 0x80

# Открыть все каналы
i2ctransfer -y 0 w1@0x70 0xFF

# Закрыть все каналы
i2ctransfer -y 0 w1@0x70 0x00
```
