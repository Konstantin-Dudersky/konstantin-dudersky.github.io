Основные характеристики:
- 16 каналов
- Создание ШИМ сигналов с амплитудой 5 В, частотой от 24 до 1526 Гц
- Управление через гальванически изолированный CAN-интерфейс

Область применения:
- Управление RC-сервоприводами в робототехнике
- Регулирование яркости светодиодов, RGB-светильников и светодиодных лент
- Регулирование мощности нагревателей
- Формирование задания скорости для драйверов двигателей постоянного тока

Все каналы модуля работают на общей частоте ШИМ, которая задаётся в настройках модуля. Для каждого канала можно независимо задать коэффициент заполнения и момент начала импульса.

Выходы модуля предназначены для управления входами внешних драйверов и контроллеров. Мощные нагрузки (двигатели, светодиодные ленты, клапаны, нагреватели) необходимо подключать через соответствующие силовые каскады.

Для индикации состояния выхода подключается модуль [EKLD-18](/modules/description/ekld-18).

## Описание

import Schematic from "./EKIO-PWMx16/schematic.svg";

ШИМ сигнал генерируется чипом **PCA9685**. Чип управляется по шине I²C с гальванической изоляцией **CA-IS3021**.
