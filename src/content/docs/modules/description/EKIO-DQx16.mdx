Основные характеристики:
- 16 каналов
- Постоянное напряжение от 2 до 50 В
- Ток до 200 мА на канал
- Управление через гальванически изолированный CAN-интерфейс

Область применения:
- Управление электроаппаратурой через промежуточные реле (контакторы, блоки питания)
- Управление светосигнальной аппаратурой (индикаторы, сигнальные лампы, сирены)
- Формирование дискретных сигналов управления для внешних устройств автоматики (контроллеры, частотные приводы)

Напряжение на выходах определяется внешним источником питания.

Для индикации состояния выходов подключается модуль [EK-LD-18](/modules/description/ek-ld-18).

## Описание

<Schematic />

Модуль управляется по протоколу I²C из шины IBus. Для обеспечения гальванической изоляции используется I²C-изолятор **CA-IS3021**.

GPIO расширитель **MCP23017** получает команды по шине I²C и управляет выходами.

Сигналы с GPIO расширителя поступают на транзисторную сборку **TBD62783**.


[^1]: **CA-IS3021** - https://e.chipanalog.com/products/interface/isolated/i2c/1298
[^2]: **MCP23017** - https://www.microchip.com/en-us/product/mcp23017.
