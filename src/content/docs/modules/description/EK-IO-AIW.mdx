Основные характеристики:
- 4 канала подключения тензодатчиков
- К разным каналам возможно подключение тензодатчиков с разными характеристиками
- Нет необходимости в использовании балансировочной коробки
- Разрешение до 24 бит
- Встроенная фильтрация сигналов
- Скорость опроса до 4.8 кГц
- Передача данных через гальванически изолированный CAN-интерфейс

Область применения:
- Измерение веса с помощью тензодатчиков
- Измерение веса подачи материала в дозаторах
- Контроль веса бункеров, силосов
- Измерение силы сжатия и растяжения
- Контроль натяжения (трос, лента)

## Описание

<ImageCenter
    label="Функциональная схема модуля EK-IO-AIW"
    width="700px"
>
    <Schematic alt="Функциональная схема модуля EK-IO-AIW"/>
</ImageCenter>

На плате установлен микроконтроллер **ESP32-C3**, который опрашивает АЦП по интерфейсу SPI и отправляет данные во внутреннюю шину IBus через CAN-шину.

Распиновка микроконтроллера **ESP32-C3**:

- SPI
    - MOSI - GPIO 3
    - MISO - GPIO 4
    - SCK - GPIO 1
    - CS - GPIO 0
- CAN:
    - RX - GPIO 1
    - TX - GPIO 0

**ESP32-C3** передаёт данные на CAN-шину через CAN-трансивер **CA-IS3050**.
